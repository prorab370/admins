# Engine Sim — APK для телефона (Capacitor)

Приложение запускается в альбомной ориентации, во весь экран. На телефоне включается лёгкий профиль:
пружины и крупные детали свечей заменены процедурными аналогами (1,2 млн → ≈540 тыс. △), без теней, bloom, MSAA и stencil-разреза,
графика «Низкая/Средняя», стрелки приборов обновляются через кадр, HDRI не качается по сети.

## Способ 1 (проще): сборка в облаке GitHub, ничего ставить не нужно
1. Создай репозиторий на github.com (можно приватный) и залей в него ВСЁ из этой папки, включая скрытую `.github`
   (проще всего через GitHub Desktop: Add local repository → Publish; либо `git init`, `git add .`, `git commit`, `git push`).
2. Вкладка **Actions** → «Build APK» (запускается сама после push; или Run workflow).
3. Через 8–10 минут: открой запуск → внизу **Artifacts → EngineSim-apk** → скачай, распакуй → `EngineSim.apk`.
4. Скинь на телефон и установи (разреши «Установку из неизвестных источников»). Нужен Android 8+ с обновлённым Android System WebView.

## Способ 2: локально (нужны Node.js 18+, JDK 17 и Android SDK)
Запусти `build-apk.bat` (нужны переменные JAVA_HOME = JDK 17 и ANDROID_HOME). Готовый `EngineSim.apk` появится рядом.

Управление на телефоне: педали газа и сцепления справа, передачи R N 1–5 и «Ручник» снизу, жесты — вращение камеры.
Если двигатель разрушен перегревом, появляется кнопка «Починить двигатель».
