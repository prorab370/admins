# Simulation Moteur V1.3.1 — исходники для работы с кодом

Веб-игра (симулятор двигателя и вождения): HTML + CSS + JS, 3D на three.js. Проект собран из распакованного APK (`app.zip`)
и разложен по структуре, как `admins-main`: исходники отдельно, `scripts/` для сборки, APK собирается через Capacitor.

## Запуск для разработки (быстро, без сборки APK)
```
npm start
```
Откроется `http://localhost:8080`. Нужен Node.js 18+, `npm install` для этого **не нужен**. Правишь файл → обновляешь страницу.
Проверка синтаксиса и ссылок (в том числе файлов языков): `npm run check`.

## Как ориентироваться в `src/app.js`
Файл большой, но не минифицирован и подробно прокомментирован (по-французски). Блоки подписаны заголовками вида
`/* ===== НАЗВАНИЕ (V1.x.x) ===== */` — ищи по ним (Ctrl+F `=====`).

## Смена версии игры
Номер версии стоит в 4 местах, меняй все вместе (иначе в игре будут разные номера, а 3D может не запуститься):
1. `<title>SIMULATION MOTEUR V…</title>` в `index.html` — источник истины, `app.js` читает версию отсюда;
2. подпись `id="versionTag"` в `index.html` (показывается до старта скрипта);
3. `RENDU3D_V` в `src/loader.js`;
4. `var VERSION` в `assets/route3d.js` — игра не стартует 3D, если он не совпадает с `RENDU3D_V`.

Файлы `generateur.js` и `langues/*.js` подключаются с `?v=<RENDU3D_V>`, отдельно версию в них менять не нужно.

## Сборка APK (как в admins-main)
**Облако GitHub:** залей папку в репозиторий (вместе с `.github`) → вкладка Actions → «Build APK» → Artifacts → `SimulationMoteur.apk`.
**Локально:** Node.js 18+, JDK 17, Android SDK (`JAVA_HOME`, `ANDROID_HOME`) → запусти `build-apk.bat`.
В зависимостях, кроме Capacitor, есть `@capacitor/filesystem` и `@capacitor/share` — через них игра экспортирует сохранение.

> а склейка частей обратно даёт исходный `index.html` байт в байт.

## Что намеренно не перенесено
- Нативная часть исходного APK: dex-код, ресурсы, `AndroidManifest.xml`, проверка лицензии Google Play, плагины AdMob и Billing.
  Capacitor-проект создаётся заново, `appId` — заглушка `com.example.simmoteur`. Без плагинов реклама и покупки в игре просто не активны.
- Игра опубликована в Google Play под другим автором (пакет `com.grimvex.simmoteur`); в `assets/pub-admob.js` лежат его рекламные ID.
  Не публикуй сборку со своим именем/этими ID без разрешения автора — для своей версии поставь свои ID или убери рекламу и покупки.
